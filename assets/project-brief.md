# Professional Portfolio & Career Showcase Website

## Project Overview

Build a modern, mobile-friendly personal portfolio website designed to showcase my professional background, technical expertise, work experience, achievements, certifications, case studies, and project portfolio.

The primary goal of this website is to help recruiters, hiring managers, clients, and potential employers evaluate my qualifications for both full-time employment and freelance opportunities.

The website should function as a digital CV/resume while providing a richer and more engaging experience than a traditional PDF resume.

The design should emphasize professionalism, credibility, technical competence, measurable business impact, and personal branding.

---

# Technical Constraints

## TC-1: Technology Stack

Use only:

* HTML
* CSS
* Vanilla JavaScript (ES6+)

Do NOT use:

* React
* Vue
* Angular
* Svelte
* jQuery
* Bootstrap
* Tailwind CSS
* TypeScript

---

## TC-2: Data Storage

No backend server required.

Portfolio content should be stored as JavaScript objects and rendered dynamically.

---

## TC-3: Browser Compatibility

Must work correctly on:

* Chrome
* Firefox
* Edge
* Safari

---

## TC-4: Responsive Design

Must support:

* Mobile
* Tablet
* Desktop

Use a mobile-first approach.

---

## TC-5: Project Structure

```text
portfolio/
│
├── index.html
│
├── css/
│   └── style.css
│
├── js/
│   └── app.js
│
├── assets/
│   ├── profile/
│   ├── projects/
│   ├── certificates/
│   ├── company-logos/
│   ├── cv/
│   └── documents/
│
└── README.md
```

---

## TC-6: File Rules

* Only 1 CSS file inside css/
* Only 1 JavaScript file inside js/
* No external frameworks
* No build tools
* No package manager required
* Use semantic HTML
* Keep code clean and readable
* Keep implementation simple and maintainable
